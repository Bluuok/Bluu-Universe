AGY CLI要求登录，未运行反重力测试；采用安装版Chrome与未参与修改的原生独立评审。整体星海造型、所有极端视角、跨GPU及真实系统失焦未全面验收；外部软边界仍按角色原点，相机避障和身体碰撞分别记录。
