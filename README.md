## 操作

- 无需按鼠标键，移出中心死区控制左右/上下方向；回中心停止转向。默认不前进、不滚转。
- W沿三维方向推进，松W惯性滑行，S刹车。A/D平移，Space/Shift升降。
- P暂停/继续，Esc暂停或退出面板，H/「回到入口」一键返航；真实UI、转场和失焦清输入；返回画布先回中心恢复转向。
- 锁鼠按钮仅为可选用户手势，不是起飞前提。
- 对准门廊向内飞入自动进屋；出屋后先飞离范围再重新靠近才能再次触发；展品/目录打开介绍，返回原SPACE/ROOM，室内点「返回星海」出门。
- 保留触控按钮；默认静音，音效按钮仅短交互音。
